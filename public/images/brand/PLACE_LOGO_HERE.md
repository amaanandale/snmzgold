# ⬇ Place Your Official Logo Here

Drop your logo file(s) into this folder:

| File | Purpose |
|---|---|
| `snmz-logo.svg` | **Primary logo** — used in Header & Footer (on dark backgrounds) |
| `snmz-logo-light.svg` *(optional)* | Light/inverted variant for use on light backgrounds |
| `snmz-logo-dark.svg` *(optional)* | Dark variant if the primary is white/light |

## Requirements
- Preferred format: **SVG** (transparent background)
- Fallback format: **PNG** with transparent background (min 400 px wide, 2× for retina)
- Do **not** rename to anything else — the codebase references `snmz-logo.svg` exactly.
- Once you drop the file here, the Header and Footer will use it automatically.
